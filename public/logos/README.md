# Technology logos

Locally served SVG assets; no runtime CDN or icon-font dependency.

- React, Next.js, TypeScript, Node.js, PostgreSQL, Python, Three.js, Tailwind CSS, Git, Docker, and Figma: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), MIT. See `DEVICON-LICENSE` for the original license.
- `gsap.svg`: the GreenSock brand mark from [Simple Icons 15.0.0](https://www.npmjs.com/package/simple-icons/v/15.0.0), original file [`icons/greensock.svg`](https://cdn.jsdelivr.net/npm/simple-icons@15.0.0/icons/greensock.svg), CC0 1.0. See `SIMPLE-ICONS-LICENSE.md`.

Devicon files retain their upstream brand colors. Next.js and Three.js use an off-white fill (`#f0efe9`) for the dark surface. GreenSock uses `#88ce02`. These marks identify the respective technologies; their trademarks belong to their owners.

Source filenames: `react/react-original.svg`, `nextjs/nextjs-plain.svg`, `typescript/typescript-original.svg`, `nodejs/nodejs-original.svg`, `postgresql/postgresql-original.svg`, `python/python-original.svg`, `threejs/threejs-original.svg`, `tailwindcss/tailwindcss-original.svg`, `git/git-original.svg`, `docker/docker-original.svg`, `figma/figma-original.svg`.
